One sentence, 221 characters, that would convince a friend who has never coded to let an AI agent build their first app idea on make.fun:

> That app idea you've been carrying around — describe it in plain words on make.fun and an AI agent will build it for you, no code needed and nothing to lose, so the only thing between you and your own app is one sentence.

`main.ts` (Node 22) writes that sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt`, guarded to the competition's 1–240 character gate. Seven candidate pitches were drafted and compared against the judge's criteria in order — on-task, persuasion, clarity, truth, warmth and craft — and the reasoning is recorded in the comments at the top of `main.ts`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts && cat /tmp/out/entry.txt
```
